# User Documentation

Reference docs for configuring and running the simulator. Start with the
[project README](../README.md) for build and quick-start instructions, then come
here for the details.

| Doc | What it covers |
|-----|----------------|
| [INPUT_FORMAT.md](INPUT_FORMAT.md) | Complete physics-engine JSON reference: units, equations, vehicles, mass, batteries, control/passive effectors, force sources, trim, sensors. |
| [connections.md](connections.md) | The `connections` section: UDP/file telemetry channels, packet formats, and field reference. |
| [graphics-config.md](graphics-config.md) | Graphics-engine JSON: camera, ground, vehicle meshes, HUD, sky, UDP packet mapping, and subprocess launch. |

For the controllers (flight modes, gamepad map, control-law designs) see
[controllers/README.md](../controllers/README.md). For ready-to-run aircraft see
[examples/README.md](../examples/README.md).
